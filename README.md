# Chatwoot × Agno — Support lab

Статическая демостраница поддержки EdgeCenter для GitHub Pages.

## Запуск

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. В GitHub Settings → Pages выберите **Deploy from a branch → main → /(root)**. Зависимости и сборка не нужны.

## Настройка

`config.js` содержит только адрес Chatwoot и **публичный websiteToken** Website-канала. Это идентификатор виджета, не API-токен бота. API-токен, секрет подписи webhook, ключи модели и базы данных должны оставаться в Vault и в серверном окружении Agno. Не добавляйте их в этот репозиторий или GitHub Pages.

`agentConnected` управляет информационным уведомлением, а не подключением агента. Переключайте его в `true` только после сквозной проверки. Индикатор «Виджет готов» подтверждает загрузку Chatwoot, но не ответ Agno.

## Серверная цепочка

Браузер → Chatwoot Website inbox → AgentBot webhook → Agno → Chatwoot → виджет.

Нужны развёрнутый обработчик `/integrations/chatwoot/webhook`, корректные `CHATWOOT_*` настройки Agno, доступ между сервисами и назначение AgentBot нужному Website inbox. На сервере должны проверяться подписи webhook. Сам по себе GitHub Pages не запускает Agno и не получает его ключи.

## Передача человеку

После подключения интеграции сообщение **оператор** переводит диалог из `pending` в `open`. Agno прекращает отвечать; оператор принимает тот же диалог с историей. Передача в очередь не означает, что оператор уже онлайн или назначен. У источника должны быть соавторы/операторы.

Кнопки сценариев копируют текст и открывают официальный виджет. Пользователь сам вставляет и отправляет сообщение. Страница не использует приватный API Chatwoot, не имитирует ответы и не создаёт обращения автоматически.

## Приёмка

1. Виджет загружается с опубликованной страницы; новый вопрос появляется в Chatwoot.
2. Agno отвечает; уточнение использует контекст беседы.
3. После перезагрузки в том же браузере переписка сохраняется.
4. Сообщение «оператор» открывает обращение для человека; следующий вопрос не вызывает ответа бота.
5. Оператор отвечает в том же диалоге, и ответ виден посетителю.
6. Проверить мобильный экран, клавиатуру и состояние недоступности Chatwoot.

Тестовый Chatwoot может требовать доступ к корпоративной сети. Доступность страницы GitHub Pages не обеспечивает сетевую доступность Chatwoot.
